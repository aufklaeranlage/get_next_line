get next line
=============

## Description

This project is about reading from a file desscriptor until a new line character is found or the EOF is reached. It was the first introduction to `static` variables to keep data from previous executions in memory for later use.

## Instructions

We were supposed to create a function that could read from a single file descriptor and return a newly allocated string that contains all characters until a new line character (`\n`) or EOF was found. For the bonus we had to extend the usage to also deal with a set of file descriptors and keep the state for all of them separate.
